    Google Tasks Sync

    Two-way sync with Google Tasks: your tasks appear in Google (and inside Google Calendar's Tasks panel), and checking one off or deleting it on either side syncs on your next sync. Everything stays in a dedicated list called Work Flow Assist, so your other Google tasks are untouched.

    One-time setup
    1. Open the Google Cloud Console and create a project.
    2. Enable the Google Tasks API (APIs & Services → Library).
    3. Configure the OAuth consent screen (External), and add your own Google account under Test users.
    4. Create an OAuth Client ID → type Web application. Under Authorized JavaScript origins add your app's address (e.g. https://YOU.github.io, or http://localhost:8000 for local testing).
    5. Copy the Client ID and paste it below.
